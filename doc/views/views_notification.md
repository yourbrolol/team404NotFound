# Views: Notifications

## NotificationListView
- **Path**: `app.views.views_notification.NotificationListView`

### Overview
Displays all notifications for the currently logged-in user.

---

## MarkNotificationReadView
- **Path**: `app.views.views_notification.MarkNotificationReadView`

### Overview
Marks a single notification as read. If the notification contains a link, the user is redirected to that destination.

---

## MarkAllReadView
- **Path**: `app.views.views_notification.MarkAllReadView`

### Overview
Marks all unread notifications for the current user as read.

# ContestKeeper Documentation Guide

Welcome to the documentation for ContestKeeper, a Django-based platform for organizing and managing contests.

## Navigation

This documentation is organized into several key areas to help you understand the system, set up your development environment, and contribute effectively.

### High-Level Overview
- [Documentation Plan](docplan.md) - The master plan and roadmap for documentation.
- [Architecture](ARCHITECTURE.md) - System design, data flow, and core entity relationships.
- [API Reference](API_REFERENCE.md) - Detailed guide to all available endpoints.

### Developer Guides
- [Quick Start for Developers](QUICK_START_DEV.md) - Environment setup and first contribution guide.
- [Troubleshooting](TROUBLESHOOTING.md) - Common issues and how to resolve them.

### Detailed Component Docs (Work in Progress)
The following directories will contain detailed documentation for each layer of the application as outlined in the [Documentation Plan](docplan.md):
- `models/` - Database layer and entity documentation.
- `views/` - Controller/View logic and routing.
- `forms/` - Form validation and processing.
- `services/` - Core business logic.
- `frontend/` - Templates, CSS, and JS guides.

## How to use these docs
These documents are written in Markdown and are designed to be viewed in any Markdown-compatible viewer (GitHub, VS Code, etc.). 

If you are a new developer, we recommend starting with the [Quick Start for Developers](QUICK_START_DEV.md) to get your local environment running.
